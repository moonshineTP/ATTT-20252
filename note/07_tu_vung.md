## Tiếng Anh → Tiếng Việt

| Tiếng Anh | Tiếng Việt | Viết tắt |
|---|---|---|
| Public Key Infrastructure | Hạ tầng khóa công khai | PKI |
| Certificate Authority | Tổ chức/Nhà cấp phát chứng chỉ số | CA |
| Registration Authority | Tổ chức đăng ký | RA |
| Digital Certificate | Chứng chỉ số / Chứng thư số | — |
| Public Key | Khóa công khai | KP / PK |
| Private Key | Khóa riêng / Khóa bí mật | KR / SK |
| Key Pair | Cặp khóa | — |
| Certificate Revocation List | Danh sách thu hồi chứng chỉ | CRL |
| Online Certificate Status Protocol | Giao thức kiểm tra trạng thái chứng chỉ trực tuyến | OCSP |
| Certificate Signing Request | Yêu cầu ký chứng chỉ | CSR |
| Trust Anchor | Điểm tin cậy gốc | — |
| Root CA | CA gốc | — |
| Intermediate CA | CA trung gian | Int CA |
| End-Entity | Thực thể cuối | — |
| Chain of Trust | Chuỗi tin cậy | — |
| Digital Signature | Chữ ký số | — |
| Non-repudiation | Chống chối cãi / Không chối cãi | — |
| Man-in-the-Middle | Tấn công trung gian | MITM |
| Hardware Security Module | Mô-đun bảo mật phần cứng | HSM |
| Distinguished Name | Tên phân biệt | DN |
| Subject Alternative Name | Tên thay thế của chủ thể | SAN |
| Key Usage | Mục đích sử dụng khóa | — |
| Extended Key Usage | Mục đích sử dụng khóa mở rộng | EKU |
| Domain Validated | Xác thực tên miền | DV |
| Organization Validated | Xác thực tổ chức | OV |
| Extended Validation | Xác thực mở rộng | EV |
| Certificate Transparency | Minh bạch chứng chỉ | CT |
| Certificate Lifecycle Management | Quản lý vòng đời chứng chỉ | CLM |
| Perfect Forward Secrecy | Bảo mật hoàn toàn về phía trước | PFS |
| Automated Certificate Management Environment | Môi trường quản lý chứng chỉ tự động | ACME |
| Decentralized Identifier | Định danh phi tập trung | DID |

## Viết Tắt Thuật Toán

| Viết tắt | Đầy đủ | Dùng trong |
|---|---|---|
| RSA | Rivest-Shamir-Adleman | Mã hóa, chữ ký là |
| DSA | Digital Signature Algorithm | Chữ ký số |
| ECDSA | Elliptic Curve DSA | Chữ ký số hiệu quả hơn RSA |
| ECDH | Elliptic Curve DH | Trao đổi khóa |
| AES | Advanced Encryption Standard | Mã hóa đối xứng |
| SHA-256/384/512 | Secure Hash Algorithm | Hàm băm |
| MD5 | Message Digest 5 | Hàm băm (đã lỗi thời) |
| HMAC | Hash-based Message Authentication Code | Xác thực thông điệp |
| TLS | Transport Layer Security | Bảo mật tầng vận chuyển |
| SSL | Secure Sockets Layer | Phiên bản cũ của TLS |

## Thuật Ngữ Trong Giáo Trình

| Từ trong giáo trình | Thuật ngữ chuẩn |
|---|---|
| Chứng thư số | Digital Certificate |
| Khoá công khai | Public Key |
| Khoá riêng / Khoá mật | Private Key |
| Bên cấp chứng thư số | Certificate Authority (CA) |
| Trung tâm cấp phát chứng thư số | CA |
| Chứng thực khóa công khai | Public Key Authentication |
| Phân phối khóa | Key Distribution |
| Trao đổi khóa | Key Exchange |
| Hệ mật khóa công khai | Public Key Cryptosystem |
| Mã hóa bất đối xứng | Asymmetric Encryption |
| Mã hóa đối xứng | Symmetric Encryption |
